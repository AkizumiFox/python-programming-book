# Python 入門：從寫程式到看懂軟體世界

作者：林子祐（國立臺灣大學資訊工程學系）

一本給完全沒有程式經驗的人的 Python 教科書，28 章、636 頁。前半從變數、條件、迴圈、函式到檔案與例外處理；後半講模組、產生器、物件、正規表示式、自動化日常工作、API 與網路請求，最後兩章談軟體產業的實際運作方式與接下來可以學什麼。讀者設定從國中生到沒寫過程式的上班族，例子先於定義，不預設任何工具經驗。內容來自我在臺大經濟系與通識課擔任 Python 助教兩年的觀察。

- 完整 PDF：[`output/book.pdf`](output/book.pdf)
- 原始碼：`src/`（XeLaTeX，`make book` 重新編譯）
